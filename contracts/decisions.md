# Decision status for this public set

The service contracts originated as draft proposals. Their original decision ledger included historical coordination and a pending exact-set agreement checkpoint; it is not included in this selected public specification set. A proposed numeric limit, compatibility profile, durability guarantee, or other product choice in a draft contract does not become an accepted release promise merely because the draft is published.

The [adopted practical v1 scope](../ADOPTED-SCOPE.md) records the later release-scope decision. The [SSH lifecycle amendment](../coordination/amendments/ssh-openssh-lifecycle-r1/amendment.md) records the specific later cleanup decision. Where these documents supersede a wider draft requirement, use the later adopted boundary for practical v1 and retain the original as historical full-spec work. Evaluation still requires exact artifact identity and actual passing observations.
