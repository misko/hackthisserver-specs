[Caddy v2.11.7 release notes](https://github.com/caddyserver/caddy/releases/tag/v2.11.7) were reviewed for default timeout regressions, cutoff streams and current Incremental field support. A request-body deadline cannot outlive its owning exchange and terminate unrelated subsequent output; map NGX-07/10. [RFC 10036](https://www.rfc-editor.org/rfc/rfc10036.html) is an optional newly registered field, not automatically a required profile capability. This web proposal declares it unsupported and forwards its ordinary end-to-end value opaquely; no claim of incremental-delivery support is made. If later supported, a positive request must be honored incrementally or explicitly refused per the RFC, and complete-exchange design assumptions must be revisited. This disposition prevents silent import of an infinite streaming scope.
